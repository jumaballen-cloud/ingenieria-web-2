# Cookie Game

## Descripción

En este proyecto implementé un sistema de pedidos para Cookie Game que permite explorar un catálogo de videojuegos, agregar productos a una lista de pedidos y realizar un seguimiento simulado de las compras. Los pedidos se almacenan localmente en el navegador y se asocian al usuario autenticado.

## Requisitos

- Node.js 22.12 o superior
- npm
